# Quote Generator App

A simple full-stack Quote Generator app where users can view random quotes and submit their own. The app consists of a frontend and a backend:

- **Frontend:** Displays quotes, allows users to submit new ones.
- **Backend:** Stores quotes and serves them to the frontend via an API.

## Features
- View a random quote
- Submit a new quote with author
- Quotes are stored on the backend

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
